PROJECT OVERVIEW

About NewsScope AI

An intelligent news article analysis platform designed to transform unstructured articles into useful insights.

PROJECT DESCRIPTION

What is NewsScope AI?

NewsScope AI is a Python Flask-based full-stack web application that allows users to upload news articles and automatically analyze their content.

The system extracts text from TXT, PDF and PNG files, performs sentiment analysis, identifies the article category, extracts important points and stores the analysis results in a SQLite database.

Users can search, view and manage previously analyzed articles through a professional web dashboard.

PROBLEM STATEMENT

Why was this project created?

News articles are produced in large quantities and can be difficult to manually classify, understand and compare. NewsScope AI provides a centralized system that extracts and analyzes article information automatically.

OBJECTIVES

Project Goals

  • Upload news articles easily.
  • Extract text from different file types.
  • Analyze article sentiment.
  • Classify articles by category.
  • Identify important article points.
  • Store analysis results.
  • Search and manage historical analyses.
KEY FEATURES

What can users do?

  • TXT, PDF and PNG upload.
  • PDF text extraction.
  • PNG OCR processing.
  • Article preview.
  • Sentiment detection.
  • Category classification.
  • Main-point extraction.
  • History and deletion.
  • Category and sentiment search.
